# Distance Calculator

## Description
A Python command-line tool that calculates the straight-line (Euclidean) distance between two sets of coordinates, \((x_1, y_1)\) and \((x_2, y_2)\), in a 2D Cartesian plane using the Pythagorean distance formula.

## How to Run the Program
1. Ensure you have **Python 3** installed.
2. Open your terminal or IDE.
3. Download or save the code into a file named `distance_calculator.py`.
4. Run the file using:
   ```bash
   python distance_calculator.py
   ```

## Input Needed
* **x1, y1:** Numerical coordinates for Point 1.
* **x2, y2:** Numerical coordinates for Point 2.

## Sample Output
```text
--- Distance Calculator between Two Points ---
Enter x1: 1
Enter y1: 2
Enter x2: 4
Enter y2: 6

The distance between the two points is: 5.00
```
